A push rebuilds the site, so `site.time` IS the last commit — no API, no build step, no rate limit. Lit or dark it links to the Direct Line: the light on the Creator's desk leads to the line that reaches his desk. The drawing is _sass/_pjcc-24-desk-lamp.scss, which sizes the lamp but never PLACES it. Each caller positions it: the splash pins it to the corner of the viewport, the front door stands it in the flow of a band. Wrap this include in something positioned. Caller may pass `id` to make the element addressable; it defaults to studio-light. ══════════════════════════════════════════════════════════════════════════════ {%- endcomment -%} {%- assign lamp_id = include.id | default: 'studio-light' -%} {%- comment -%} The upper arm, elbow, head and cone are wrapped in .sl-upper so the lamp can FOLD as a rigid unit when it sleeps (2026-07-22) — the wrapper rotates about the elbow, swinging the head down while it stays attached to the lower arm, instead of each part being flung separately. .sl-upper is position:absolute;inset:0, so its children keep the exact coordinates they had as direct siblings; with no fold applied (the lit state) it is completely inert. The desk, lower arm and base stay put — the parts that rest ON the desk. {%- endcomment -%} {%- comment -%} ⚠ THE CHECK IS A FILE, NOT AN INLINE SCRIPT, AND IT MAY NEVER COME BACK IN HERE (2026-08-04). This include is used from a `.md` page (index.md, the front door), and kramdown eats an inline script there in one of two ways depending only on what wraps it: escaped to a syntax error inside a span, or truncated at the first BLANK LINE inside a div — which printed forty lines of this function on the live front door as a code block. Both failures and the whole reasoning are written up at the top of the .js file. `defer` so it runs after the markup it looks for; it is idempotent and scoped by class, so a page carrying two lamps is fine. {%- endcomment -%}
