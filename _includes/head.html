WHY THE MANIFEST ALONE CANNOT DO THIS. `start_url` is baked into a launcher AT INSTALL TIME. An icon added to a home screen in June still opens `/pjcc/?source=pwa` — the front door of the day — no matter what manifest.json says today, and there is no API that reaches back into an installed launcher to correct it. Editing the manifest fixes the NEXT install and nothing else. So the fix has to live on the page the old launcher lands on, and it has to be a redirect. ⚠ IT KEYS ON `?source=pwa`, WHICH IS THE WHOLE SAFETY. That marker only exists on URLs the manifest itself hands out — a launch. Every other route to /pjcc/ (the drawer, the front door's world card, a shared link, Google) arrives without it and is untouched, so the world tab is still a real page you can visit inside the app. Only `/pjcc/` is rewritten; the manifest's four shortcuts carry the same marker and must keep working.
