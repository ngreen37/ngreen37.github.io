No reading, no account, one tap, an instant verdict. This page is that mechanic escalated exactly once: six of them, climbing, ending in a number about YOU. People will do almost anything for a number about themselves. ── THE FOUR RULES THIS PAGE INHERITS FROM THE FRONT DOOR ──────────────────────── 1. THE BOARD IS THE BUTTON. There is no start screen, no "ready?", no explanation of what a puzzle is. Position one is on the screen when the page opens. Anything that stands between a stranger and the first piece is a chance to leave. 2. NO ENGINE ON THE PAGE. Every position here was proved at BUILD time by the real perft-verified referee (tests/gen-rating-puzzles.js, `npm run gen:rating`). This page compares two integers and reads a packed move list. It does not reason about chess and it never makes a claim the referee did not make. [[accuracy-above-all]] 3. A LEGAL MOVE, THEN A VERDICT. Picking a piece up lights its legal moves and a square that is not one of them cannot be played at all. Being told you failed a chess puzzle for doing something that is not a chess move is the worst version of being wrong — the front door shipped that bug once and it is not shipping here. 4. A DOOR, NEVER AN ESCORT. Nothing auto-advances. Every screen waits for a tap. ── THE NUMBER, AND WHY IT IS NOT A NEW OPINION ABOUT CHESS ────────────────────── Every puzzle in the pool carries the rating the PUZZLE ROOM gave it — the same scale the site's solver Elo and clearance already run on ([[clearance-and-puzzle-elo]]). So the run is a six-question measurement on a ruler this site already owned, not a second opinion invented for a landing page. The estimate is a standard adaptive Elo settle with a decaying K: serve at the current estimate, settle, repeat. ⚠ THE CEILING IS REAL AND THIS PAGE SAYS SO OUT LOUD. The room's rating formula tops out near 1600, so six of these cannot measure a 2000 player. A clean sweep is told, in plain words, that the test ran out of road — and pointed at Robert (2400), who will not run out. Do NOT "fix" this by inventing ratings the room never claimed; a number built on a false claim is a lie about a person. [[no-excuses-copy]] ⚠⚠ THE RESULT IS NOT WRITTEN TO THE PROFILE, AND THAT IS DELIBERATE, NOT AN OMISSION. Clearance is the MAX of the rating and credit ladders, so a solver Elo seeded from an anonymous six-question run that anyone can retake until it goes well is a clearance exploit wearing a friendly face. The standing rule on every economy number is err miser — loosening later is a gift, tightening later is a takeaway ([[sell-back-economy]]).
